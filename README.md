# 神笔马良 · AI 文生图工具

单页 Web 应用，通过画笔拖拽或文本描述，调用 AI 图像生成服务产出图片。支持内置 imagegen 服务与自定义 OpenAI 兼容 API（文生图 / 图生图）两种数据源。

## 项目价值

### 面向用户

需要快速生成和二次创作图像的创作者群体——设计师、运营人员、内容编辑、电商与新媒体从业者，以及对 AI 绘画感兴趣的普通用户；同时面向已部署自建 AI 图像服务（如 Xinference、OpenAI 兼容网关）的团队，提供低门槛对接工具。

### 核心能力

1. **中文提示词一键生图**：文生图 / 图生图双模式，内置 20 种风格（水墨、国风、赛博朋克等），提示词自动中译英并增强，提升出图质量与相关性
2. **双数据源**：开箱即用的内置图像生成服务 + 任意 OpenAI 兼容接口（文生图 / 图生图），支持自由配置模型与尺寸
3. **异步任务并发**：任务提交秒级返回，最多 10 路并发生成，出图进度实时展示，避免长请求超时
4. **灵活出图参数**：常见比例预设（1:1、16:9、手机/电脑屏）+ 自定义尺寸（64-2048），一次可生成多图对比
5. **历史记录与下载**：生成图片自动本地留存（上限 50 条），灯箱预览、一键下载；申请下载可获取去除显式标识版本（保留隐式元数据）
6. **模型调试面板**：一键检测接口连通性、模型列表与生成链路，快速定位故障
7. **合规与审计**：用户协议确认、调用记录留存 ≥6 个月、下载图片含隐式溯源元数据

### 解决问题

1. **AI 绘图工具配置门槛高、接口不兼容**——统一兼容 OpenAI 接口，支持自定义 API 无缝接入
2. **提示词表达不准、出图质量差**——中译英 + 风格映射 + 质量词注入，中文用户零门槛
3. **长生成任务易超时中断**——异步任务模式彻底绕开网关超时，任务排队不再卡死
4. **多任务串行排队耗时长**——10 路并发，完成一张展示一张
5. **图片接口故障难排查**——内置调试面板，连通性、模型、生成链路一键自检

### 实现效果

1. 用户输入中文描述即可生成高质量图片，256x256 约 5s、1024x1024 约 80-130s 出图，多任务并发平均提速 5-10 倍
2. 内置服务开箱即用，无需任何配置；自定义接口可精确输出任意尺寸（实测 640x384 精确返回）
3. 对接故障从"不可用"变为"可诊断"，调试面板可定位模型缺失、网关配置、连通性三类问题
4. 图生图支持参考图二次创作，一次生成多图对比，创作效率显著提升
5. 任务提交秒级响应，长耗时生成全程可见，操作体验流畅

## 功能特性

- **文生图 / 图生图**：输入中文提示词生成图片；图生图模式下上传参考图片后基于参考图生成
- **双数据源**：
  - 内置服务：开箱即用，无需配置
  - 自定义 API：任意 OpenAI 兼容的图像生成接口，支持 `/images/generations` 与 `/images/edits`
- **风格选择**：内置 20 种风格（水墨、国风、赛博朋克、油画、浮世绘等），自动转为英文描述注入提示词
- **提示词增强**：自定义模式下，中文提示词先自动翻译为英文，再拼接风格描述与质量词后发送，提升生成质量与相关性
- **尺寸预设 + 自定义**：常见比例预设（1:1、3:2、16:9、9:16 电脑/手机屏等），支持自定义宽高（64-2048）
- **异步任务**：生成采用"提交任务 + 轮询状态"模式，避免长请求超时；任务排队串行执行
- **历史记录**：生成图片自动保存到浏览器本地（上限 50 条），支持灯箱预览与下载
- **模型调试**：内置调试面板，可检测自定义接口连通性、模型列表与生成链路
- **TinyPNG 压缩**：图片卡片与灯箱新增「压缩」按钮，经 TinyPNG 官方 API 无损压缩后下载；API Key 内置在服务端（`start.sh` 的 `TINIFY_API_KEY`），用户无需配置
- **合规下载**：页面展示与生成均保留显式标识；用户主动申请下载时输出去除显式标识的图片，并写入隐式元数据（生成任务、调用人、时间），用于溯源与合规审计
- **用户协议**：首次进入应用需阅读并同意协议；协议版本更新后重新确认
- **调用记录留存**：结构化审计日志按天分片留存不少于 6 个月（含调用人、请求参数、输出记录），仅用于安全审计与合规管理
- **毛笔作画动效**：生成期间展示毛笔沿墨迹轨迹作画的 loading 动画

## 快速开始

### 依赖

- Node.js 18+

### 启动服务

```bash
# 1. 安装桥接层依赖
cd .mcp/imagegen-bridge
npm install

# 2. 启动服务（内置 imagegen 服务地址来自环境变量）
IMG_URL="https://<sse-imagegen-host>/sse" \
IMG_TOKEN="<token>" \
PORT=8000 \
node server-http.mjs
```

启动后访问 `http://localhost:8000/` 即可使用。

> 前端静态资源缓存采用 `?v=` 版本号控制，修改前端文件后请同步递增 `web/index.html` 中的版本号。

## 使用说明

### 内置服务

默认数据源。输入提示词、选择风格与尺寸后点击「开始生成」。内置服务支持 7 种固定尺寸：

`256x256` / `512x512` / `1024x1024` / `1536x1024` / `1024x1536` / `1792x1024` / `1024x1792`

选择自定义尺寸时，后端会按宽高比自动映射到最接近的固定尺寸。

### 自定义 API

点击右上角「设置」，切换数据源为「自定义 API」并填写：

| 配置项 | 说明 |
|--------|------|
| API 基础地址 | 如 `https://api.example.com/v1`，自动兼容带 `/images/generations` 后缀的地址 |
| API Key | 请求 Bearer Token |
| 模型 | 图像生成模型名称 |

自定义模式支持：

- 任意尺寸（64-2048），实测自定义尺寸可精确生效
- 图生图（`/images/edits`）
- 提示词自动中译英 + 风格增强
- 生成结果统一转 base64 返回，兼容返回本地路径 url 的网关

### TinyPNG 压缩

压缩 API Key 内置在服务端：在 `start.sh` 中填写 `TINIFY_API_KEY`（tinypng.com/developers 获取，免费额度 500 张/月）后重启服务即可，用户无需任何配置。生成结果卡片与灯箱中的「压缩」按钮会调用后端压缩图片并下载，压缩比例实时提示。

## 后端 API

| 接口 | 说明 |
|------|------|
| `POST /api/generate` | 提交生成任务，body 含 `source`(builtin/custom)、`prompt`、`n`、`size`、`style`；custom 需 `baseURL`/`apiKey`/`model`，图生图附 `imageDataUrl` |
| `POST /api/generate-3d` | 3D 渲染直出专用接口：免 key，body 仅需 `prompt`；固定 `style=3d_render`、`size=256x256`、每次 1 张、内置通道；返回 jobId 后轮询 `/api/status/:jobId` |
| `GET /api/status/:jobId` | 轮询任务状态：`pending`/`processing`/`done`/`error`，完成时返回 `images`（base64 dataURL 数组） |
| `POST /api/debug/model` | 自定义接口连通性检测：归一化 base、模型列表、生成测试（含耗时/响应体） |
| `GET /api/agreement` | 获取用户协议（版本/标题/内容） |
| `POST /api/agreement/accept` | 确认同意协议，记录调用人+版本 |
| `POST /api/download` | 申请下载无水印版本：body 传 `{jobId,index}` 或 `{imageDataUrl}`；须先同意协议（否则 403 `needAgreement`）；返回 PNG（去显式标识 + 隐式元数据） |
| `POST /api/compress` | TinyPNG 压缩：body 传 `{imageDataUrl}`（key 内置服务端 `TINIFY_API_KEY`）；返回 `{imageDataUrl,width,height,bytes,originalBytes,ratio}` |

任务由后端 Promise 链串行排队执行，避免并发挤兑图像服务。

## 常见问题

- **生成较慢**：自定义接口耗时与尺寸强相关，256x256 约 5s，1024 约 80-130s；任务为串行排队，多个任务需依次等待
- **内置服务不支持图生图**：请切换到自定义 API 模式
- **图片显示为裂图**：自定义网关若返回本地路径 url，后端已自动按 base64 抓取兜底；确认请求携带 `response_format: b64_json`
- **预览域名无法访问**：预览地址末尾不要带 `/`
