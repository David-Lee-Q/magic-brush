## 三、稳定性与故障回归测试

以下为真实环境出现过的问题及修复后的回归结果：

| 问题 | 根因 | 修复方案 | 回归结果 |
|------|------|----------|----------|
| 生成无结果（MCP error -32000） | SSE 长连接空闲被远端关闭 | 每次请求新建连接 + 瞬时错误自动重试（最多 3 次） | 连续 26 任务零失败 |
| HTTP 500 / 长请求超时 | 预览网关 30-60s 长请求中断 | 改为异步任务模式（202 + 轮询） | 单请求秒级，稳定 |
| 图片裂开/无法显示 | base64 提取吞入后续中文文本，data URL 污染 | 逐行提取 + `^[A-Za-z0-9+/=]+$` 校验 + validate 解码 | 图片正常展示 |
| 自定义接口返回本地路径 url | 网关返回服务器本地路径 | 请求统一带 `response_format: b64_json`；公网 url 后端抓取转 base64 | 实测"粉色海豚"10s 返回合法 JPEG |
| 畸形编码路径导致进程崩溃 | `decodeURIComponent('%')` 抛 URIError 未捕获 | try/catch 返回 400 | `/%` → 400，进程存活；`/` → 200 |

## 四、安全回归

- 静态目录穿越请求（`../` 越界）→ 403
- 请求体超 1MB → 拒绝并断开
- 空提示词 / 未配置 baseURL → 400
- 请求日志不包含 API Key 与令牌

功能需求 8/8 通过，并发任务成功率 100%（26/26），关键故障点均已修复并经回归验证。**结论：测试通过，具备申报与交付条件。**
