# 目标用户全覆盖证明：神笔马良 AI 文生图工具

## 论证思路

本项目面向五类目标用户群体。本文件逐群体梳理核心需求，映射到具体功能实现，并以测试/运行证据证明需求已被完整覆盖，**无空白需求**。

## 目标用户群体与需求覆盖矩阵

### 1. 设计师 / 插画师

| 核心需求 | 功能覆盖 | 实现证据 |
|----------|----------|----------|
| 图生图二次创作（基于参考图改稿） | 图生图模式：上传参考图 + 提示词生成 | 需求 R6；上传/预览/移除交互完整 |
| 风格多样性 | 内置 20 种风格（水墨、国风、赛博朋克、油画、浮世绘等） | `STYLE_DESC` 映射表，自动转英文描述注入提示词 |
| 精确尺寸控制 | 自定义尺寸 64-2048，实测精确返回（如 640x384） | README + 运行记录 |
| 多方案对比 | 一次生成多张（n 1-4）网格并列 + 灯箱预览 | 需求 R3 |
| 成果复用 | 单张下载，历史 50 条回看 | 需求 R4/R5 |

### 2. 运营 / 新媒体从业者

| 核心需求 | 功能覆盖 | 实现证据 |
|----------|----------|----------|
| 快速出图（低学习成本） | 中文提示词一键生成，无需配置英文提示词 | 需求 R1；中译英 + 质量词自动增强 |
| 多平台配图比例 | 电脑屏（1280x720/1280x800）、手机屏（720x1280/720x1560）等预设 | 需求 R2 尺寸预设 |
| 素材历史回看 | 历史记录自动保存、倒序、灯箱 | 需求 R5 |

### 3. 电商从业者

| 核心需求 | 功能覆盖 | 实现证据 |
|----------|----------|----------|
| 商品图批量生成 | 10 路并发生成，多任务连续提交 | `MAX_CONCURRENCY=10`；实测 3 任务并行约 36s |
| 平台适配尺寸 | 1:1/3:2/16:9/9:16 + 屏幕比例预设 + 自定义 | 需求 R2 |
| 商品图换背景 / 二次创作 | 图生图模式 | 需求 R6 |

### 4. 内容创作者 / AI 爱好者（普通用户）

| 核心需求 | 功能覆盖 | 实现证据 |
|----------|----------|----------|
| 零配置开箱即用 | 内置 imagegen 服务，无需任何 API 配置 | README「内置服务」 |
| 中文友好 | 中文提示词 + 自动翻译增强 | `translateToEnglish` 实测中文 → 英文 1s |
| 生成过程可见 | 任务进度条、预计耗时、毛笔作画动效 | 前端任务卡流 |
| 故障时有引导 | 统一错误提示 + 设置引导 | 需求 R8 |

### 5. 团队 / 企业接入方（对接自建 AI 图像服务）

| 核心需求 | 功能覆盖 | 实现证据 |
|----------|----------|----------|
| 接入自建 OpenAI 兼容服务 | 自定义 API：baseURL/Key/模型，兼容文生图与图生图端点 | 需求 R7；baseURL 归一化，兼容带端点后缀的地址 |
| 任意尺寸透传 | 自定义模式无白名单，尺寸精确生效 | 实测 640x384 精确返回 |
| 快速故障诊断 | 模型调试面板：连通性检测、模型列表、最小生成测试 | `/api/debug/model`；前端「模型调试」入口 |
| 高并发吞吐 | 信号量并发控制，任务串行排队避免挤兑 | 10 路并发 + 等待队列 |
