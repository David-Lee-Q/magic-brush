快速上手

神笔马良是一款 AI 文生图工具：输入一句话描述，即可自动生成对应画面的图片，也支持基于参考图生成相似风格的新图。

第一步：在左侧输入框中输入画面描述（支持中文），例如「一只在月光下展翅的仙鹤，仙气飘飘」。
第二步：选择风格、尺寸与数量。
第三步：点击「开始生成」，等待画面生成，结果会显示在中间结果区，可预览、缩放与下载。

生成流程与预览

页面采用左中右三栏布局。生成面板位于左侧，包含模式、提示词、风格、尺寸与数量等选项；中间为核心结果区；右侧为历史记录。

生成流程

结果区顶部展示完整生成流程，直观呈现一次生成经历的五个阶段：

  • 描述输入：接收并解析你的提示词。
  • 理解转写：中文提示词自动翻译为英文，提升模型理解。
  • 风格增强：结合所选风格附加画面细节描述。
  • 成图输出：模型生成图片并回传。
  • 预览下载：在结果区预览，可放大查看或下载到本地。

预览效果

生成完成后，结果区会以缩略图网格展示全部图片。点击任意缩略图，弹出灯箱按原图比例预览。

灯箱工具栏

  • 缩小 / 放大：点击工具栏的「−」/「+」按钮，或按住 Ctrl / ⌘ 滚动鼠标滚轮缩放，范围为 50%-400%。
  • 还原：点击「还原」按钮，或按 0 键，回到 100% 原始比例。
  • 下载：点击「下载」将当前预览图片保存为 PNG 文件。
  • 关闭：点击右上角「关闭」按钮，或按 Esc、点击弹窗外部区域。

工具栏左侧实时显示当前缩放比例（如 100%、175%）。图片始终按原始比例等比缩放，自动适配窗口大小，不出现滚动条。

多图与平移

  • 多图切换：一次生成多张时，工具栏提供「上一张 / 下一张」，也可按键盘 ← / → 切换；右上角显示当前序号（如 1 / 3）。
  • 拖拽平移：放大后按住图片拖动，可查看画面的其他区域。

结果区与右侧历史记录面板高度对齐，图片较多时在各自区域内滚动查看。

生成图片

选择生成模式

控制面板顶部提供两种模式：

  • 文生图：仅凭文字描述生成新图。
  • 图生图：上传一张参考图，基于参考图内容与提示词生成新图。该模式需要切换至「自定义 API」数据源；使用内置服务时「图生图」标签会置灰，点击将弹出切换提示。

图生图模式下点击「上传参考图」选择本地图片（不超过 10MB），上传后立即显示预览缩略图，可点击右上角按钮移除并重新上传。

输入提示词

  • 支持中文或英文，建议描述主体、环境、风格与氛围，如「一只在月光下展翅的仙鹤，仙气飘飘」。
  • 使用自定义 API 生成时，中文提示词会自动翻译为英文并附加风格描述，以获得更好的效果。

选择风格

内置 20 种风格，如水墨、国风、赛博朋克、油画、浮世绘等。风格会影响画面的整体气质，选择「不指定」则由模型自由发挥。

设置尺寸

预设尺寸

下拉框中提供多种常用比例，标签中已注明宽高比：

  • 常规：1:1、3:2、2:3、7:4 等
  • 电脑屏幕：16:9、16:10、4:3
  • 手机屏幕：9:16、9:19.5、3:4

自定义尺寸

选择「自定义尺寸…」后输入宽和高（64-2048 像素之间）。内置服务仅支持固定尺寸，自定义尺寸会按比例自动匹配最接近的预设；自定义 API 模式支持任意尺寸精确生成。

设置数量

单次可生成 1-4 张。数量越多耗时越长，建议按需选择。

自定义 API

使用内置服务开箱即用；如需图生图、任意尺寸或更好的生成效果，可切换至自定义 API。

配置步骤

  1. 点击页面右上角「设置」按钮。
  2. 数据源选择「自定义 API」。
  3. 填写 API 基础地址（如 https://api.example.com/v1）、API Key 与模型名称。
  4. 点击「保存配置」。

API 基础地址兼容 OpenAI 格式接口，支持 /images/generations（文生图）与 /images/edits（图生图）。

校验配置

配置不确定是否正确时，可在设置弹窗底部点击「模型调试」，检测接口连通性、查看模型列表，并实际生成一张测试图验证。模型是否可用以调试结果为准。

版本信息

点击页面顶栏的信息图标按钮，可查看当前版本号、发布日期与更新内容。

历史记录

历史记录面板位于页面右侧栏，成功生成的图片会自动保存到浏览器本地（最多保留 50 条），刷新页面不会丢失。每条记录展示模式标签（线框样式，文生图为金色、图生图为蓝色）、时间、尺寸与风格，风格以中文显示。

  • 预览：点击历史缩略图可放大查看，支持缩放与多图切换。
  • 下载：放大预览后点击「下载」保存图片。
  • 删除：鼠标悬停到记录右上角，点击删除图标可移除单条记录。
  • 清空：点击「清空」可删除全部记录。

常见问题

生成耗时多久？

耗时与模型及尺寸强相关：小尺寸（256x256）约 5 秒，中尺寸（512）约 10-30 秒，大尺寸（1024）约 80-130 秒。多个任务会排队串行执行，请耐心等待。

内置服务为什么不能图生图？

内置图像服务暂未开放图生图能力，页面中「图生图」标签会置灰且不可选中。请切换至「自定义 API」模式，且该接口需支持 /images/edits 并配置可用的图像编辑模型。

自定义 API 提示模型不存在怎么办？

在设置弹窗中点击「模型调试」查看接口实际返回的模型列表，确认模型名称填写正确。部分网关的模型列表可能不完整，可结合接口文档确认模型名。

生成失败或图片显示异常怎么办？

  • 提示「生成失败」：请检查网络与接口配置，自定义 API 模式请确认地址、密钥正确且服务可达。
  • 图片裂图：确认接口支持 b64_json 返回格式；部分网关会返回服务器本地路径，系统会自动抓取转换。

如何提升生成效果？

提示词越具体越好（包含主体、环境、光线、风格）；自定义 API 模式下建议搭配风格选项，中文提示词会自动增强。
